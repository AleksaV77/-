# Введение в ООП

## Описание проекта:
```
Созданее классов Product и Category
```

## Классы, которые мы будем использовать:
```
- class Product. Содержит данные о товаре: название, описание, цену, количество в наличии
```
```
- class Category. Содержит данные о товаре: название, описание, список товаров категории
```
```
- В класс Category добавлены два атрибута для подсчёта количество категорий и количество товаров.
```

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/AleksaV77/-.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
