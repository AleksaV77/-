# Введение в ООП

## Описание проекта:
```
Созданее классов Product и Category
```

## Классы, которые мы будем использовать:
```
- class Product. Содержит данные о товаре: название; описание; цену; количество в наличии; 
класс-метод, который взвращает созданный объект класса Product; сеттер с проверкой цены на 0 и ниже
```
```
- class Category. Содержит данные о товаре: название; описание; список товаров категории;
метод для добавления товаров; геттер для вывода списка товаров
- class Product. Содержит данные о товаре: название; описание; цену; количество в наличии;
```
```
- class Category. Содержит данные о товаре: название; описание; список товаров категории;
```
```
- В класс Category добавлены два атрибута для подсчёта количества категорий и количества товаров.
```
```
Добавлены классы для двух категории товаров (Smartphone и LawnGrass) с дополнительными свойствами.
```
```
Добавлена функциональность для сложения товаров только из одинаковых классов продуктов.
```
```
Доработан метод, для добавления продукта в категорию, чтобы не было возможности добавить 
вместо продукта или его наследников любой другой объект.
```
```
Доработан базовый абстрактный класс BaseProduct, для класса продуктов.
```
```
Доработан класс-миксин для печати в консоль информацию о том, от какого класса 
и с какими параметрами был создан объект.
```

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/AleksaV77/-.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
